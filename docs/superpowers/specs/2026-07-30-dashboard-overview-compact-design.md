# 运营总览紧凑布局设计

## 目标

降低运营总览区域的纵向高度，使其与左侧供水网络地图更协调，同时保留全部六项指标及现有视觉语义。

## 布局

- 大屏下六张指标卡片采用两列三行网格。
- 卡片使用更小的内边距与间距，数字字号适度缩小。
- 运营总览容器不再依赖单列撑满高度。
- 窄屏下自动切换为单列，避免文字与单位拥挤。

## 范围

- 仅调整 `Dashboard.css` 中运营总览区域及其内部卡片样式。
- 不改动指标数据、图标、颜色、顺序或业务逻辑。
- 不影响其他页面对通用 `DataCard` 组件的使用。

## 验证

- 运行 TypeScript/Vite 构建。
- 确认大屏为两列三行，窄屏为单列。
- 确认六项指标完整可读且无溢出。
