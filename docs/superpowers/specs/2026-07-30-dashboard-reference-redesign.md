# 运营驾驶舱参考图改版设计

## 目标

将现有运营驾驶舱改造为参考图所示的信息密集型大屏布局，保留现有左侧菜单、顶部栏以及青黑色玻璃拟态配色。页面使用现有业务数据，并以稳定的演示数据补齐七日趋势、压力监测和维修分类等缺失维度。

## 页面框架

- 保留 `MainLayout` 的左侧菜单和顶部栏。
- 仅重做 `/dashboard` 内容区。
- 内容区采用“顶部指标 + 左中右三栏 + 底部信息栏”结构。
- 大屏优先展示，普通桌面允许页面纵向滚动；平板及窄屏自动改为单列或双列，不出现横向溢出。

## 信息架构

### 顶部核心指标

横向展示六项指标：

1. 覆盖人口
2. 供水工程
3. 今日供水量
4. 水质达标率
5. 在线监测点
6. 累计维修工单

每项显示主值及一个辅助信息，例如覆盖率、正常工程数量、昨日供水量、环比、在线率或已完成工单数。数值优先来自现有 service；缺失辅助值使用稳定演示数据，不使用每次渲染变化的随机数。

### 左侧分析栏

从上到下展示：

1. 水质达标情况：环形图，显示达标、不达标、未监测数量及达标率。
2. 水质达标率趋势：最近七日折线图。
3. 供水量统计：最近七日柱状图。
4. 水源状况：正常、预警、风险水源数量及枯水风险提示。

### 中心主区域

1. 供水工程分布：二维地图作为主视觉。
   - 使用现有县域 GeoJSON、村庄和供水点坐标。
   - 展示供水点状态散点和村庄名称。
   - 提供全部、正常、预警/异常筛选。
   - 点击供水点显示名称、所属村庄、类型、状态和覆盖人口。
2. 实时监测数据：位于地图下方。
   - 列包括监测点、所属区域、水质达标率、浊度、余氯、pH、状态、更新时间。
   - 使用在线水质最新记录和供水点、村庄数据聚合。

### 右侧运营栏

从上到下展示：

1. 告警统计：最近七日总量和分类环形图。
2. 工单处理情况：待处理、处理中、已完成及办结率。
3. 维修类型 TOP5：横向条形图。
4. 管网压力监测：正常点、低压点、高压点及七日趋势。

告警分类由现有 `indicator` 字段规则映射；维修类型由报修描述关键词归类；压力数据使用智慧村庄现有压力指标生成稳定的七日演示序列。

### 底部信息栏

1. 最新告警：显示告警类型、位置、时间和状态，优先展示待处理记录。
2. 快捷入口：跳转至基础台账、水质管理、设备管理、工单管理、报表统计、巡检管理、智慧村庄等现有路由。

## 组件边界

在 `pages/Dashboard/components` 下拆分：

- `DashboardKpiBar`
- `QualityCompliancePanel`
- `QualityTrendPanel`
- `WaterVolumePanel`
- `SourceStatusPanel`
- `EngineeringMap2D`
- `RealtimeMonitorTable`
- `AlertStatsPanel`
- `WorkOrderPanel`
- `RepairTypePanel`
- `PressurePanel`
- `LatestAlertsPanel`
- `QuickEntryPanel`

`Dashboard/index.tsx` 只负责加载数据、组织布局和传递 props。图表组件负责自己的 ECharts option，不在页面文件内堆积配置。

## 数据层

- 扩展 `dashboardService.ts`，集中生成驾驶舱视图模型。
- 新增驾驶舱专用类型，描述 KPI、七日序列、实时监测行、告警分类、工单统计、维修分类和压力趋势。
- 新增稳定演示数据文件，所有演示序列为固定值或由现有数据确定性计算。
- 不修改现有村庄、供水点、设备、水质、告警和报修的核心数据结构。

## 视觉要求

- 沿用现有 CSS 变量及 `glass-card` 风格。
- 不复制参考图的亮蓝色主题，不修改全局主题。
- 使用青色作为主强调色，绿色表示正常，橙色表示预警，红色表示故障。
- 面板标题、边框、图表文字与现有页面保持一致。
- 控制卡片高度和留白，确保首屏信息密度接近参考图。

## 移除与替换

新版驾驶舱不再单独展示：

- 村庄速览卡片
- 原三项饼图横排
- 原分村运营与安全状况表
- 原季节性缺水风险标签区

这些信息分别整合到地图、水源状况、实时监测表和运营统计面板中。

## 异常与加载

- 保留现有加载状态。
- 单项数据为空时，对应面板显示“暂无数据”，其他面板继续展示。
- 页面数据加载失败时显示错误提示，不让整个页面空白。
- 图表随容器尺寸变化自动调整。

## 验证标准

- 大屏下形成顶部六指标、左中右三栏和底部双栏结构。
- 中心二维地图明显大于两侧面板，并可筛选供水点状态。
- 所有参考图主要信息区域都有对应展示。
- 现有主题颜色、左侧菜单和顶部栏保持不变。
- 页面在 1366px、1920px 和窄屏下无横向溢出。
- TypeScript、lint 和 Vite 构建通过。
